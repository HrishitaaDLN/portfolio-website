# Hrishitaa — Software Engineer - AI Portfolio

A stunning, fully animated personal portfolio built with **Next.js 14**, **Tailwind CSS**, **Framer Motion**, and **tsParticles**.

## Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- Framer Motion
- tsParticles (hero neural network background)
- @lottiefiles/react-lottie-player
- react-icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- **Resume**: Place `resume.pdf` in `/public` for the Download Resume button.
- **Certifications**: Edit `CERTIFICATIONS` in `lib/data.ts` (see inline comment).
- **Project GitHub links**: Update `github` URLs in `lib/data.ts`.
- **OG image**: Replace `/public/og-image.png` or update metadata in `app/layout.tsx`.

## Build

```bash
npm run build
npm start
```

## Features

- Dark theme with cyan/violet accents
- Custom glowing cursor (desktop)
- Typewriter hero roles
- Glassmorphism cards with hover glow
- Section scroll reveals
- Animated SVG robot, LLM diagram, neural brain, research globe
- Sticky frosted navbar
- Mobile hamburger menu
- Contact form UI
